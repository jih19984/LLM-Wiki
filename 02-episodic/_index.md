# 02-episodic

날짜별 세션/학습 로그가 쌓이는 곳입니다. `_templates/daily-log.md`를 복사해서 씁니다.

- 파일명 규칙: `YYYY-MM-DD-주제.md` (예: `2026-08-15-이진탐색트리.md`)
- 같은 내용이 여기 2회 이상 반복 등장하면 `03-semantic/`으로 승격을 고려합니다.
- 오래된 로그를 지울 필요는 없습니다 — 검증된 결론만 semantic으로 뽑아가면 됩니다.
