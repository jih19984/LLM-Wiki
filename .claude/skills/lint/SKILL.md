# /lint — 지식 창고 자가 치유

## 대상

볼트 전체. **단, `01-working-memory/`(raw, 미처리 원본)는 절대 수정하지 않는다.** 그 안의 캡처는 아직 검증 전 상태이므로 lint 대상 밖이다.

## 검진 항목

1. **고아(Orphan) 노트**: 어떤 MOC에도, 어떤 노트의 `related`/`relationships`에도 걸리지 않은 `03-semantic/`, `04-procedural/` 노트.
2. **누락된 태그**: `tags`가 비어있거나 `type` frontmatter가 없는 노트.
3. **깨진 링크**: 본문·frontmatter의 `[[wikilink]]`가 실제 존재하지 않는 파일을 가리키는 경우.
4. **상충되는 정보(Contradiction)**: 서로 다른 노트가 같은 주제/엔티티에 대해 다른 내용을 주장하는 경우 (예: 같은 라이브러리 버전, 같은 담당자, 같은 설정값에 대한 서로 다른 값).

## 처리 방식

- **고아 노트**: 자동으로 아무 MOC에나 연결하지 않는다. 폴더 위치상 소속 MOC이 명백한 경우는 바로 링크를 추가해도 되지만, 애매하면 후보 MOC을 제안하는 리포트만 작성한다.
- **누락된 태그**: 리포트에만 포함한다. 자동으로 채우지 않고 `/tag` 실행을 제안한다.
- **깨진 링크 — 자가 치유(자동 복구)**: 깨진 링크의 텍스트와 파일명이 일치하는 노트를 볼트 전체에서 찾는다.
  - 일치하는 파일이 정확히 하나면 → 그 경로로 링크를 자동 수정한다.
  - 일치하는 파일이 없거나 여러 개면 → 자동 수정하지 않고 리포트에 남겨 사용자에게 묻는다.
- **상충 정보 — 제안만, 자동 덮어쓰기 금지**: 두 노트가 상충하면 각각의 `confidence`와 `updated` 날짜를 비교해 "이 노트가 더 최신/신뢰도 높으니 이렇게 병합하는 게 어때요?"라고 제안한다. 사용자 승인 전에는 절대 병합·삭제하지 않는다.

## 완료 후 보고 (리포트 형식)

- 고아 노트 목록 + 제안 MOC
- 누락 태그 노트 목록
- 자동 복구한 깨진 링크 목록 (before → after)
- 복구 못한 깨진 링크 목록 (사용자 확인 필요)
- 발견된 상충 정보와 병합 제안 (사용자 승인 대기)
